## Featured project — AutoFleet-Edge

[Explore the project and demo →](https://github.com/abhi1228-DAM/autofleet-edge#demo)

A ROS 2 learning project that drives a simulated differential-drive vehicle to named destinations using odometry feedback.

**Stack:** Python · ROS 2 Humble · Gazebo Fortress · Docker on Apple silicon

- Supports named destinations and explicit coordinate targets.
- Adjusts heading and forward speed using position feedback.
- Includes stop conditions for arrival, stale odometry, bridge loss, timeout, and cancellation.
- Includes 16 offline tests covering control calculations, target selection, and stopping decisions.

**Documented simulation observations:** two named-destination runs reported final target errors of **3.5 cm** and **6.6 cm**, within the configured **10 cm arrival tolerance**. These are individual odometry-based observations, not a repeatability benchmark.

**Current scope:** single-vehicle coordinate control in simulation. Obstacle avoidance, mapping, fleet coordination, and natural-language task parsing are future work.

This is an AI-assisted learning project built around an upstream ROS-Gazebo demo. The repository identifies the project-specific controller, tests, integration work, and upstream credits.
